## 4.0.0

### Breaking Changes

* **libopus is built from source by a build hook.** `opus_codec_dart` compiles its vendored libopus and a small CTL shim into a native code asset during `dart build`, `flutter build`, `dart test` and `flutter test`. Native builds need a C compiler: Xcode on Apple platforms, the Android NDK on Android, gcc or clang on Linux, MSVC on Windows.
* **The native platform packages are retired.** `opus_codec_android`, `opus_codec_ios`, `opus_codec_linux`, `opus_codec_macos` and `opus_codec_windows` are no longer used or released. Remove any direct dependency on them; `opus_codec` and `opus_codec_dart` cover every platform.
* **`opus_codec.load()` is removed.** Replace `initOpus(await opus_codec.load())` with `await opus_codec.initializeOpus()`.
* **`initOpus()` takes no library on native.** Passing one throws `ArgumentError`. On web, `initOpus(library)` still takes the `wasm_ffi` `DynamicLibrary`.
* **`OpusFlutterPlatform.opusVersion` is removed.** Use `getOpusVersion()`, which reports the linked library (for example `libopus 1.6.1`).
* **`OpusFlutterPlatform.load()` is web-only.** Native platforms have no implementation.
* **`opus_packet_parse` declares its real C types** (`frames[48]`, `size[48]`) in the wrapper bindings.
* **`encoderCtl` accepts integer-valued setter requests only.** Getter requests return `OPUS_BAD_ARG` instead of reaching libopus.
* **Raised SDK floors.** Dart 3.10 for every package; Flutter 3.38.1 for the Flutter packages (3.38.0 ships a pre-release Dart 3.10).
* **Narrowed native targets.** Built: macOS arm64 and x64, iOS arm64 (device and simulator) and x64 (simulator), Android arm, arm64 and x64, Linux x64 and arm64, Windows x64. Windows x86 is no longer built.

### Changes

* **libopus 1.6.1** (was 1.5.2), vendored from Xiph's release archive and verified against Xiph's published SHA-256. Native and web compile the same sources. This release uses generic C only; the SIMD paths of the 3.x binaries are not included.
* Native bindings are generated by ffigen as `@Native` declarations bound to the code asset. Native initialization never loads a system libopus or extracts a library to a temporary directory.
* The libopus licence is included in `opus_codec_dart`'s `LICENSE`.
* Calling `initOpus()` again is a no-op, so live encoders and decoders keep their backend.

### Bug Fixes

* Zero the soft-clip state before use. `pcmSoftClip` and decoders with `autoSoftClip` could output values far outside [-1, 1] when the allocator returned uninitialised memory.
* Packet-loss concealment works. A missing packet (`null` input, or `inputBufferIndex = 0`) passed the loss in milliseconds where libopus expects samples, so it always failed with `OPUS_BAD_ARG`.
* `BufferedOpusDecoder` FEC recovers only the lost duration. It used to decode the whole output buffer (240 ms at 48 kHz stereo) and ignored `loss`. This also affected `StreamOpusDecoder` with `forwardErrorCorrection`.
* `lastPacketDurationMs` is correct for stereo; it reported half the real duration.
* `SimpleOpusDecoder.decodeFloat(autoSoftClip: true)` clips the whole stereo frame, not only its first half.
* A `loss` larger than the output buffer throws `RangeError` instead of letting libopus write past the buffer.
* `OpusPacketUtils` rejects an empty packet with `OPUS_BAD_ARG` instead of reading past it.
* `StreamOpusEncoder` no longer emits an extra silent frame when the input ends on a frame boundary, and with `fillUpLastFrame: false` no longer throws `UnfinishedFrameException` in that case.
* **`StreamOpusDecoder` emits concealment audio for lost packets** (breaking). Each `null` element now yields audio as long as the previous packet, so the output keeps its timing. Before, the concealed audio was decoded and dropped. Without FEC, it also wasn't concealment: the decoder decoded the previous packet a second time. With `forwardErrorCorrection`, a loss still pending when the input ends is concealed then.
* **A lost packet before the first decoded packet no longer ends a `StreamOpusDecoder` stream** (breaking). It used to fail with `StateError`. There is nothing to conceal yet, so it is skipped and decoding continues.

## 3.0.5

### Bug Fixes

* Fix output buffer sizing for `BufferedOpusDecoder` (was 4x too small for float output) and inverted multiplier in `StreamOpusDecoder`
* Fix `opus_encoder_ctl` variadic ABI mismatch under WASM by adding a non-variadic C wrapper
* Prevent `asTypedList` view detachment on WASM memory growth by returning Dart-heap copies
* Always copy streaming output to the Dart heap, eliminating use-after-write hazards in `StreamOpusEncoder` and `StreamOpusDecoder`
* Guard encoder/decoder methods against use after `destroy()` with `OpusDestroyedError`
* Attach `Finalizer` to encoder/decoder classes for GC-driven native resource cleanup
* Prevent memory leak when a second native allocation throws
* Add `_asString` bounds guard (cap at 256 bytes) to prevent unbounded scanning
* Register missing `OpusCustomMode` opaque type in `init_web.dart` (was duplicating `OpusRepacketizer`)
* Export `_opus_encoder_ctl` in WASM Dockerfile `EXPORTED_FUNCTIONS`

### Refactoring

* Extract duplicated encode logic into `_createOpusEncoder` and `_doEncode` / `_encodeBuffer` helpers
* Extract duplicated decode logic into shared helpers and replace magic numbers with named constants
* Deduplicate `OpusPacketUtils` with a shared `_withNativePacket` helper
* Simplify `getOpusVersion` implementation
* Add `bytesPerInt16Sample` and `bytesPerFloatSample` constants in `opus_dart_misc.dart`

### Chores

* Add `repository` field to pubspec and `CHANGELOG.md`
* Fix typos across comments and documentation
* Add RFC 6716 validation note to `maxDataBytes`
* Add comprehensive tests for buffer sizing, bounds checking, use-after-destroy, and allocation failure cleanup
